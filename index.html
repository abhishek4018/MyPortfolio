The Autonomous AI Engine

01100% Schema Conformance

Autonomous JSON Self-Correction Loops

Zero user-facing breakage under schema hallucinations

EdTech demands strict data contracts across 5 standardized question types. If an LLM omits mandatory Bloom's Taxonomy metadata or creates invalid answer keys, the system catches the structural failure, feeds the traceback back into the agent loop, and recursively heals the payload before returning.

023-Tier Failover Resilience

3-Tier Circuit Breaker & Quota-Resilient Routing

Graceful failover across cloud and local LLMs with zero downtime

A three-state Circuit Breaker (CLOSED → OPEN → HALF_OPEN) paired with a thread-safe Round-Robin multi-key pool. Detects HTTP 429s and latency anomalies, cascading from Google Vertex AI / Gemini 2.5 Flash primary pools to secondary keys and finally to local Ollama (llama3.2:3b) during cloud blackouts.

Hierarchical RAG with Reciprocal Rank Fusion

Parent-child resolution preventing fragmented context

Naive 512-token chunking produces shallow questions. Vatra Assess indexes 250-token child chunks via pgvector embeddings for precise vector search, then resolves matches back to 1,200-token parent sections using Reciprocal Rank Fusion (RRF).
